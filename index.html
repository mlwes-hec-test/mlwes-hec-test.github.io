Your Data Stays Between Versions

Alpha 0.6.33 uses the same private browser storage keys as earlier Alpha 0.6 releases. Updating files at the same website address does not intentionally remove profiles, diary entries, foods, meals, recipes or lists.

Keep a readable backup before any advanced data operation or deployment change.

Advanced My Data deletion controls

Permanent Historical Data Deletion

This is HEC — My Data. A Full Reset permanently deletes the historical profile, Diary, weights, activities, My Foods, My Recipes, Shopping, companion and preferences stored in this installation.

Download and verify a full backup first. Ordinary use never requires this reset.
