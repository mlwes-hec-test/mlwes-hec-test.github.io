HEALTHY EATING COMPANION — AFCD DATA NOTICE — ALPHA 0.6.6

DATA SOURCE
Australian Food Composition Database (AFCD) Release 3
Publisher: Food Standards Australia New Zealand (FSANZ)

Healthy Eating Companion Alpha 0.6.6 includes a compact, adapted local search dataset derived from the AFCD Release 3 Food Details and Nutrient Profiles files. The app preserves the AFCD public food key for each imported record and attributes displayed records to FSANZ.

DATA LIMITATIONS
Food-composition values are reference averages. Actual nutrient content can vary between brands and batches and with season, processing practices and ingredient source. Australian food-composition data may not be appropriate for use in other countries.

The Alpha 0.6.6 local file is intended for founder-trial testing and should not be treated as a substitute for a current product nutrition panel, clinician advice or professional dietary assessment. Packaged-food values should be checked against the current product label when accuracy matters.
