capture-foundation.js
- Whole short serving labels are normalised for case, whitespace and separators
  and compared with canonical serving-size labels using at most two edits.
  Matching is anchored to a declaration, not arbitrary prose containing serving.

  metadata and a table, with an intact metric/count pair. Wrapped declarations
  and the existing one-to-twelve word-number vocabulary remain supported.
- Natural-unit correction uses the existing count/slice vocabulary. It requires
  an explicit metric serving, an explicit count, attached parentheses, at least
  four letters, one edit, and exactly one candidate unit. Household/short words
  are not fuzzy corrected. Ambiguous pachet (packet/sachet) is rejected.
- Damaged pack labels need a nutrition metadata region and clear Per Pack or
  Per Package wording. Same-length tokens allow one edit; tokens with a one-
  character length difference allow two. This accepts senings but rejects
  settings. A separated noise prefix and wrapped count are tolerated. Numeric
  fragments, signs, ranges and attached units remain invalid pack counts.
- Explicitly unit-labelled energy-only rows can be mapped using existing table
  headings, text order or word geometry. Cells remain independent, including
  weak/absent neighbouring nutrients. Reversed columns are covered.
- Damaged two-column prepared headings preserve an unresolved reference.
  The first Cal cell is accepted only when a separate explicit per-serving
  statement corroborates it; per-item prose additionally requires an explicit
  one-item-equals-one-serving declaration. Conflicting statements, weak words,
  malformed numbers and incomplete rows cannot establish that mapping.
- Raw extraction retains the corroborating row/statement and unresolved
  reference. Nothing inserts decimals, guesses units or manufactures printed kJ.
- Merge retains compatible baseline values and the existing private metric
  serving provenance when only a count was read. Shared catalogue records are
  never changed. The user still selects and confirms the source.
